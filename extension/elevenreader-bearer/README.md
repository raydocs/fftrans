# FFTrans ElevenReader Chromium Extension

Primary ElevenLabs auth path for FFTrans.

This unpacked Chromium extension pairs with FFTrans over localhost, captures ElevenReader auth data, and lets FFTrans validate/import it automatically.

## What this is for

- **Primary path:** Chrome / Chromium + this extension
- **Fallbacks in FFTrans:** manual Refresh Token entry, then legacy browser-assist only if needed
- **Not required for Firefox/Safari:** those users should use the manual Refresh Token fallback instead

## Pairing flow

1. Start FFTrans
2. In **Settings → Speech → ElevenLabs Reader**, click **Open extension folder** if you need the files
3. In Chromium, open `chrome://extensions`
4. Enable **Developer mode**
5. Click **Load unpacked**
6. Select this folder: `extension/elevenreader-bearer`
7. Back in FFTrans, click **Connect ElevenReader**
8. Finish login in ElevenReader / ElevenLabs inside Chromium
9. Return to FFTrans and click **Check again**

## What gets imported

Depending on what ElevenReader exposes, FFTrans may import:

- Refresh Token
- Bearer session token
- `xi-app-check-token`
- `Device-ID`

FFTrans prefers a validated **Refresh Token** because it survives restarts better. A bearer-only import can still work, but it may be session-only.

## Notes

- The extension connects only to `ws://127.0.0.1:39393/ext`
- It watches ElevenReader / ElevenLabs pages and related Reader API traffic
- Pairing uses a one-time token generated by FFTrans
- If Chromium + extension is unavailable, use FFTrans's manual Refresh Token fallback instead
