FFTrans ElevenLabs fallback guide

Primary path: use Chrome / Chromium + the bundled ElevenReader extension in FFTrans. Use the options below only when that primary path is unavailable.

1. Manual Refresh Token fallback

  1. Open FFTrans → Settings → Speech → ElevenLabs Reader.
  2. Expand Fallbacks: manual Refresh Token / legacy browser-assist.
  3. Paste a valid ElevenLabs / ElevenReader Refresh Token.
  4. Click Validate.
  5. After validation succeeds, click Save and finish.

This is the recommended fallback for users on non-Chromium browsers or systems where the extension is not available.

2. Legacy browser-assist fallback

  1. Use this only if the Chromium extension path is unavailable.
  2. In FFTrans, click Open legacy browser-assist.
  3. Log in to ElevenReader / ElevenLabs inside that legacy window.
  4. Return to FFTrans and click Import from legacy window.

The legacy flow may import either a Refresh Token or only a bearer-backed session. A bearer-only import can work immediately, but it may expire and need to be re-imported after restart.

3. What persists

  • Refresh Token: best fallback; survives restarts better.
  • App Check / Device ID: saved when available and useful.
  • Bearer-only session: usable now, but treat it as temporary.

4. Practical rollout note

FFTrans keeps existing ElevenLabs configs intact. If you already have a working saved Refresh Token, you do not need to reconnect the browser unless you want to re-authorize.
